# Velvet YouTube Robot

Velvet YouTube Robot is a private tool used only by Velvet Rose Noir Media to manage its own YouTube channels. It uses the YouTube Data API to set video details, publishing schedules, thumbnails, captions and playlists on channels that Velvet Rose Noir Media owns.

It is not offered to the public, and no one outside Velvet Rose Noir Media signs in to it.

Privacy policy: https://ateasalove.github.io/velvet-youtube-robot/privacy.html
